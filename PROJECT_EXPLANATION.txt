СПОРТИВНЫЙ КЛУБ: ОПИСАНИЕ ПРОЕКТА И ПРОВЕРКА КР 1
====================================================

1. НАЗНАЧЕНИЕ ПРОЕКТА
----------------------
Это консольная информационная система спортивного клуба.
Основная сущность: запись участника на тренировку.
Связанная сущность: участник клуба.

Архитектура:
Console UI -> Service -> Repository/JDBC -> PostgreSQL

База данных запускается в Docker-контейнере PostgreSQL.
Приложение можно запускать локально через Maven или целиком через Docker Compose.

2. ФАЙЛЫ ПРОЕКТА
----------------

pom.xml
Maven-конфигурация проекта. Определяет Java 17, PostgreSQL JDBC-драйвер,
Apache POI для Excel и exec-maven-plugin для запуска Main.

README.md
Краткая инструкция по установке, запуску, архитектуре и бизнес-правилам.

.env.example
Пример переменных подключения к PostgreSQL. Пароли в этот файл добавлены
только как локальные демонстрационные значения.

Dockerfile
Многоступенчатая сборка приложения. На первом этапе Maven собирает Java-проект,
на втором запускается легкий JRE-образ с классами приложения и зависимостями.

.dockerignore
Файлы, которые не копируются в Docker build context.

docker-compose.yml
Запускает два сервиса:
- postgres: PostgreSQL 16, база sportclub, пользователь postgres;
- app: консольное Java-приложение, подключенное к хосту postgres.
Также описывает volume для сохранения данных, healthcheck и автоматическую
загрузку database/schema.sql при первом создании volume.

.database/schema.sql
SQL-скрипт создания таблиц и начальных данных.
Создает таблицы members и training_registrations.
Содержит PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE и CHECK.
Добавляет 5 участников, 10 записей и несколько статусов/категорий.

database/setup-local.ps1
Скрипт для компьютера с установленным PostgreSQL без Docker.
Создает базу sportclub, если ее нет, и применяет schema.sql.
Пароль пользователя postgres вводится PostgreSQL-клиентом интерактивно.

src/main/java/ru/sportclub/Main.java
Точка входа. Создает DatabaseManager, репозитории, сервисы и ConsoleApplication.
Вся логика не находится в Main.

src/main/java/ru/sportclub/model/MembershipType.java
Enum типов абонемента: BASIC, PREMIUM, ANNUAL.

src/main/java/ru/sportclub/model/RegistrationStatus.java
Enum статусов записи: PLANNED, CONFIRMED, COMPLETED, CANCELLED.

src/main/java/ru/sportclub/model/Member.java
Модель участника клуба. Содержит private-поля, конструкторы, getters/setters
и строковое представление объекта.

src/main/java/ru/sportclub/model/TrainingRegistration.java
Модель записи на тренировку. Содержит участника, название тренировки, тренера,
дату, время, продолжительность, статус и категорию.

src/main/java/ru/sportclub/repository/CrudRepository.java
Общий интерфейс CRUD: save, findAll, findById, update, deleteById.
Используется для демонстрации интерфейса и полиморфизма.

src/main/java/ru/sportclub/repository/MemberRepository.java
JDBC-репозиторий участников. Выполняет параметризованные INSERT, SELECT, UPDATE,
DELETE через Connection, PreparedStatement и ResultSet.

src/main/java/ru/sportclub/repository/TrainingRegistrationRepository.java
JDBC-репозиторий записей на тренировки. Сохраняет и читает записи, присоединяет
имя участника, проверяет конфликт даты и времени.

src/main/java/ru/sportclub/service/MemberService.java
Сервис участников. Проверяет обязательные поля, email и наличие записи перед
изменением или удалением.

src/main/java/ru/sportclub/service/TrainingRegistrationService.java
Главный сервис предметной области. Реализует CRUD, поиск по названию и тренеру,
фильтрацию по статусу и категории, сортировку по дате и длительности,
статистику и бизнес-правила.

src/main/java/ru/sportclub/exception/BusinessException.java
Исключение нарушения бизнес-правила.

src/main/java/ru/sportclub/exception/EntityNotFoundException.java
Исключение отсутствующей записи по ID.

src/main/java/ru/sportclub/exception/DataAccessException.java
Обертка ошибок подключения и SQL-запросов.

src/main/java/ru/sportclub/util/DatabaseManager.java
Хранит настройки PostgreSQL и создает JDBC Connection.
Настройки берутся из переменных окружения с локальными значениями по умолчанию.

src/main/java/ru/sportclub/util/ExcelExporter.java
Экспортирует участников и записи на тренировки в файл
exports/sport-club-data.xlsx. Создает два листа Excel.

src/main/java/ru/sportclub/ui/ConsoleApplication.java
Интерактивное консольное меню. Принимает ввод, вызывает сервисы, показывает
результаты и перехватывает ошибки, чтобы приложение не завершалось после одной
ошибочной операции.

docs/ER-diagram.md
ER-диаграмма связей таблиц в формате Mermaid.

target/
Результаты компиляции Maven. В Git не должен включаться.

4. БИЗНЕС-ПРАВИЛА
------------------
1. Запись создается только для существующего активного участника.
2. Название тренировки и тренер обязательны.
3. Длительность тренировки от 30 до 240 минут.
4. Дата тренировки не может быть в прошлом.
5. Нельзя записать одного участника дважды на одну дату и время.
6. Новую запись нельзя создать сразу завершенной.
7. Завершить можно только подтвержденную запись.
8. Завершенную или отмененную запись нельзя редактировать.
9. Завершенную запись нельзя удалить.

5. ЗАПУСК ЧЕРЕЗ DOCKER
----------------------

В PowerShell из корня проекта:

    docker compose up --build

После этого приложение подключится к контейнеру postgres.
Docker PostgreSQL доступен с компьютера на localhost:5433, потому что
локальный PostgreSQL использует порт 5432. Внутри Compose приложения
используется адрес postgres:5432.
Ввод в консоль приложения можно выполнять прямо в терминале.

Для остановки:

    docker compose down

Для удаления базы и повторной загрузки schema.sql:

    docker compose down -v
    docker compose up --build

Важно: init-скрипты PostgreSQL выполняются только при первом создании
пустого volume. Поэтому для повторной инициализации нужен ключ -v.

6. ЗАПУСК ЛОКАЛЬНОГО ПРИЛОЖЕНИЯ
--------------------------------

Если Docker еще не установлен, PostgreSQL может работать как Windows-служба.
В этом случае выполнить из корня проекта:

    .\database\setup-local.ps1
    mvn clean compile exec:java

Приложение подключается к PostgreSQL по адресу localhost:5432.
Открывать pgAdmin для работы приложения не требуется.
